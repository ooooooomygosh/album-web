# 心流小屋 · 路线图

目标是做一间可以长期待着的像素 Lo-fi 小屋，参考 Chill Pulse 的方向：把喜欢的专辑放在身边，连接常用的播放器听歌，用番茄钟和待办专注工作；不用的时候，小屋也可以是桌面背景，小猫可以是桌宠。

## 已完成

- **1.6**：像素小屋与小猫；番茄钟、待办、统计、奖励、沉浸模式；合成环境音和离线 Lofi 电台；桌宠；动态桌面复用小屋；本地音乐和系统正在播放两个音源。
- **1.7**：只做桌面客户端。去掉了多人房间、评论、评分、AI 导览、原始展柜、Coverflow 和网页版。数据全部保存在本机，旧版本机收藏会自动迁移。界面统一为像素暖木风格，专辑详情改为小屋里的唱片卡片。

## 下一步

- **账号同步（轻量）**：只同步「我的收藏、唱片设置、专注记录」，不再引入房间等社交概念。备选方案是 WebDAV 或 iCloud / OneDrive 文件夹同步，或者一个只存个人数据的简单云端。
- **Spotify 账号**：OAuth 登录后导入收藏的专辑和歌单，用 Spotify Connect 控制播放。
- **更多场景**：雨夜书房、海边小屋等，场景之间可以切换；季节天气随日期自动变化。
- **桌宠素材包**：支持替换小猫的精灵图，增加更多动作和互动。
- **专注成长**：用书页解锁小屋的故事，跟 Chill Pulse 一样，工作推进剧情。
