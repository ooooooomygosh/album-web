## 整合审查发现与修复

1. 抽取 `shell-protocol.cjs` 时不能丢失本轮的 shell authority、请求方法及 HEAD 响应限制。已迁移限制并增加对应回归
2. 在慢封面尚未取色时，仅修改透明度或泼溅后保存，会把回退黑色错误锁为手选色。新增明确的 `autoBase: true`，旧手选色不变；保存和重载保留自动模式，显示／壁纸快照只传已解析颜色
3. 自动为唱片架取色不应占用专辑墙的高分辨率位图缓存。改为短生命周期 48px 采样，读取后释放；不降低导出专辑墙的分辨率
4. 唱机位置写入失败时恢复已保存位置并显示保存失败，不假装持久化成功
5. 合并 room 偏好时同时保留场景、petId、唱片盒与规范化唱机坐标；壁纸取消按钮保留紧凑布局的可访问名称
