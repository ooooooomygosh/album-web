# 三步入门与真实专辑展示

2026-10-09；基于已合并 PR #6 的 main `138a0d2`，独立分支 `feat/cabin-welcome-experience`。

## 呈现与实现

参考 [Zen 首页](https://zen-browser.app/) 的短定位、留白和按功能展示，以及 [HeyForm 仓库](https://github.com/heyform/heyform) 的真实产品画面；只借鉴信息组织，不复用素材。承接上一轮 README，改用十二张真实专辑的公开曲库资料和封面，补充实际界面操作短片与三步入门画面。[专辑来源](../showcase-sources.md)逐张记录；原始封面不随应用构建分发。

- 首次空白小屋显示三步指南；已有收藏或旧偏好的用户不自动弹出。右上角可重新打开，支持跳过、上一步、Esc 和键盘焦点恢复。
- 指南直接选择场景与伙伴。存储失败时显示原因并保留原选择，不伪装保存成功。
- 末步可打开专注工具、添加专辑或音源设置；不自动开始计时、登录、发声或调用原生窗口。
- 音源设置把常用账号和本地音乐放在前面，Music Assistant 服务器配置按需展开。播放与账号处理逻辑保持原样。
- 场景淡入、唱片悬停、面板与步骤切换使用短暂动效。系统减少动态与应用减少动态均可关闭；没有新增常驻动画循环。
- README 保留 v1.8.0 下载入口，并明确新向导仍是开发代码，未包含在该安装包。
