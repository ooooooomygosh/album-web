Album Circle 1.6.0 · 心流小屋：在像素 Lo-fi 小屋里收藏专辑、听歌和专注。

- 默认打开像素风温馨小屋。窗外天气（雪、晴、雨、星空）和室内光线会随本地时间变化。一只像素小猫住在屋里：听歌时跟着摇头，专注时趴在书旁陪你，深夜犯困，点一下会回应你。
- 专注工具在小屋右侧，番茄钟、待办、统计和声音分为四个标签：
  - 番茄钟：时长可调，每几轮安排一次长休息，结束时有系统通知和提示音。计时按时间戳计算，窗口隐藏或电脑休眠后依然准确。
  - 待办：可拖拽排序，选中一项后开始专注，会记录这项任务专注了几轮。
  - 统计：最近 7 天的专注柱状图、连续天数和累计时长。
  - 奖励：每完成一轮得 1 条小鱼干和经验值，升级后解锁小猫配饰（耳机、围巾、毛线帽）和窗外天气。
- 按 Z 进入沉浸模式，只留下小屋、小猫和计时。
- 声音：雨声、壁炉、风声、白噪声和黑胶底噪都由程序实时合成，可分别调节音量。「Lofi 电台」离线生成 Lo-fi 音乐，每 16 小节换一段；唱机播放音乐时会自动调低。
- 桌宠：点「小猫出门」，小猫就会出现在桌面上，窗口透明、始终置顶，只有点到小猫身上才会响应，其余区域可以直接点穿到下面的程序。
  - 小猫可以拖动，会记住你放的位置。专注时头顶显示倒计时，切歌时显示歌名。
  - 右键菜单可以开始或暂停专注、跳过休息、开关声音、调整大小，或让小猫回家。双击小猫打开小屋。
- 托盘：动态桌面和桌宠共用一个托盘图标。关闭主窗口后，计时和声音继续运行。
- 动态桌面会同步天气、小猫和专注倒计时。
- 新音源「本地音乐」：在音源设置中添加音乐文件夹，软件按标签整理成专辑，音乐留在原位置播放。在「收藏与分享」中可以把本地专辑放上唱片架：先尝试从曲库补一张公开封面，找不到时使用文件内嵌的封面，这种封面只在这台电脑上显示，分享时不可见。
- 新音源「系统正在播放」：
  - Windows 读取系统媒体控制，Spotify、网易云音乐、QQ 音乐、浏览器等正在播放的歌都会显示在唱机上，并可以暂停和切歌。
  - macOS 支持 Music 和 Spotify，首次使用需要在「自动化」中允许。
  - 「收藏这张」按钮会在曲库里搜索这张专辑，方便把它加入收藏。
- 网页版可以安装为 PWA，离线时仍能打开界面。手机竖屏下，专注工具改为底部抽屉。
- 导出的收藏文件包含专注记录与待办，导入时会询问是否一起导入。发布的分享链接不包含这些数据。

macOS 使用 ad-hoc 签名，尚未做 Apple 公证；Windows 尚未配置发布者签名，首次打开可能出现系统确认提示。系统正在播放、桌宠在多显示器下的表现，需要在实际设备上确认。
