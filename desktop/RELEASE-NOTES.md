心流小屋 1.11.0：沉入桌面、播放更省心、新手引导与统一设置。

沉入桌面（PR #14）
- 「桌面模式」和「动态桌面背景」合并成一个入口「沉入桌面」：主窗口收进托盘或菜单栏，小屋铺到桌面图标后面（Windows 用 WorkerW，macOS 用 desktop 级窗口），桌面图标照常能用。
- 桌宠和左下角的像素迷你唱机仍然可以点；迷你唱机悬停可播放、调声音、开专注，双击回到窗口。其余区域点击会穿透到桌面。
- 退出：托盘「浮出桌面」、双击托盘图标、双击迷你唱机，或按 Ctrl/⌘+Alt+D。挂不到桌面图标后面时，改用可交互的桌面窗口，并说明原因。
- 托盘和菜单栏图标跟随所选伙伴（不再总是小猫）。

播放更省心（PR #15）
- 修复 QQ 音乐专辑「每次都播放失败、要手动重新匹配」：自动匹配现在按曲名、歌手、专辑和时长打分，中英文歌手名（如 Jay Chou / 周杰伦）、Remaster 后缀不会再导致匹配失败。Live、伴奏、翻唱、Remix 不会替换原版。播不了就自动试下一个候选，成功的匹配会记下来；连续几首都播不了，就跳到下一首。
- 音质选择：标准 128k / 高品质 320k / 无损 FLAC。账号没有对应权限时自动降到能播放的最高档，唱机上显示实际播放的音质。
- 系统 Apple Music（仅 macOS）：在“音乐”App 资料库里找到同一首歌并在那里播放，小屋显示进度，可暂停和切歌。
- 小屋里播不出来时，可以「在 QQ 音乐中打开 / 在网易云音乐中打开」。这时声音由平台 App 播放，小屋不显示进度。

新手引导与统一设置（PR #16）
- 第一次打开时有新手引导：音源（登录或添加文件夹）→ 权限 → 房间与伙伴 → 播放测试 → 完成。可跳过，中途关闭下次接着来，可在「设置 › 关于」重新引导。老用户不会被打断。
- 右上角「设置」统一成六个分区：音源 · 房间与桌宠 · 专注工具 · 桌面 · 数据与备份 · 关于。旧入口会跳到对应的分区。

已验证范围（2026-10-10）：
- PR #14、#15、#16 的 GitHub Checks 已通过；合并后的 main 上 `npm run qa` 通过（单元测试 190 + 71 项，浏览器冒烟 57 项）。安装包以本标签对应的 Desktop release 工作流结果为准。
- 浏览器冒烟测试使用模拟接口与生成的音频，不代替真实账户和原生环境验收。

尚未验证：
- 未用真实 QQ 音乐／网易云账号验证自动重新匹配、会员音质降级，以及「在 App 中打开」（包括网易云 orpheus:// 链接）。
- 系统 Apple Music 与“自动化”权限请求没有在真实 Mac 上测试过。
- 沉入桌面的桌面层级（Windows WorkerW、macOS desktop 窗口）、点击穿透与托盘伙伴图标，没有在真实 Windows／Mac 上验收。

保留的限制：
- Spotify 需要开发者密钥，尚未接入。
- 从文件导入的专辑仅本次运行可直接播放，重新打开后需再选一次文件。
- macOS 使用 ad-hoc 签名，尚未 Apple 公证；Windows 尚未配置发布者签名。

收藏与专注记录仍保存在本机。升级或换电脑前，可在「设置 › 数据与备份」导出备份。发行资产提供 SHA256SUMS.txt；请按设备架构选择 macOS arm64／x64 或 Windows x64 安装包。
