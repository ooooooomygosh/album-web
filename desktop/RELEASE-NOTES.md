心流小屋 1.8.0：五种小屋场景、五位伙伴，以及音乐播放和桌面可靠性改进。

- 五场景与五伙伴可在小屋、桌宠和动态桌面同步选择，并保留选择；增加安静的伙伴散步、夜间配色、雪景、火焰与炉光效果。
- 唱机可拖动并保存位置，黑胶颜色可跟随封面；专注计时与沉浸工具改进。
- 动态桌面启动可取消，资源缺失和渲染进程异常后能退出错误状态并重试。
- 修复 QQ 播放候选镜像选择，保留原始 mediaMid 音频文件标识；不扩大音频地址白名单。修复 macOS 本地音乐目录别名移除，以及专辑删除后笔记仍自动保存的问题。
