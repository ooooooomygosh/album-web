心流小屋 1.7.0：专注于小屋本身。这一版把软件收拢成一间像素 Lo-fi 小屋，只做 macOS 和 Windows 桌面端，所有数据都保存在本机。

- 新名字、新图标：Album Circle 改名为「心流小屋」，图标换成戴耳机的像素小猫。界面统一为暖木像素风，包括方角、黄铜描边和硬阴影。
- 打开软件就进入小屋。标题栏提供「添加专辑」「收藏与备份」「专辑墙」三个入口，小屋工具栏集中放置专注、沉浸、筛选、画风、音源、桌宠和动态桌面。
- 添加专辑有三种方式：
  - 曲库搜索：Apple 曲库或 QQ 音乐，粘贴 QQ 音乐专辑链接也能识别。
  - 本地音乐文件夹。
  - 手动填写。
- 唱片卡片取代原来的专辑详情页，包含封面与黑胶、曲目、发行信息和「我的笔记」（自动保存）。点任意一首会放上唱机，从那一首开始播放。
- 筛选与唱片盒移到小屋里，支持按放上时间、年份、专辑名、歌手排序，也可以按类型、唱片盒、流派、年代筛选，筛选条件会被记住。
- 数据全部在本机：
  - 不再需要也不再提供账号。
  - 「收藏与备份」可以导出、导入唱片、黑胶外观、唱片盒和专注记录。
  - 旧版本地模式的收藏在首次启动时自动迁移。
- 删去的功能：多人房间、评论、评分、AI 导览、音乐人格、原始展柜、Coverflow、隐藏长廊、购买记录、网页版与在线分享。
- 修复：
  - 中文应用名会导致页面加载失败，现在 User-Agent 中改用 ASCII 名称。
  - 沉浸模式下计时器和退出按钮会被一起隐藏。
  - 专注面板打开时会遮住唱片架翻页按钮。

专辑笔记、黑胶外观、专注记录都只在这台电脑上。换电脑前，请先在「收藏与备份」导出备份。

macOS 使用 ad-hoc 签名，尚未做 Apple 公证；Windows 尚未配置发布者签名，首次打开可能出现系统确认提示。
