心流小屋 1.9.0：统一像素美术、月夜书桌、全新播放器与专辑导入，以及更好用的番茄钟、待办和桌宠猫。

美术与场景
- 所有房间统一为像素风，新增共享设计变量与像素字体，黑胶唱机摆上架子。
- 新增「月夜书桌」场景与书写动效（PR #8），并统一为像素风；默认房间仍为像素小屋。
- 动态桌面与纯净全屏修复（PR #8）。

播放器与专辑
- 播放控制重做：上一首／下一首、待播列表、三种循环、随机、音量与静音、快捷键和媒体键；出错时说明原因并可重试。
- 新增「自动匹配可播放音源」：按 QQ 音乐、网易云依次验证可播放的版本（PR #8）。
- 导入本机音乐文件或文件夹，读取 MP3／FLAC 标签与内嵌封面；没有封面时生成小屋配色的像素封面，唱片卡片可预览、应用与恢复原封面。
- 本地音乐接口返回空或残缺资料时不再崩溃。

效率工具
- 番茄钟：像素进度环、节奏预设（15/3、25/5、50/10、90/20），今日轮数、专注时长与连续天数。
- 待办：完成进度条、编辑与双击改名、勾选动效，本机保存；支持减少动态效果。

桌宠
- 桌宠更生动：呼吸、竖耳、被点挤压、冒爱心、晃腿、打盹，并随音乐能量摇头；桌宠窗口现在能收到播放状态与音乐能量。
- 桌宠猫可在小屋各处跳跃、行走；走路更顺滑，沉浸模式下鼠标停在控制台上时会跳回面板（PR #10）。

已验证范围（2026-10-09）：

- PR #9、#10 的 GitHub Checks（单元测试、生产构建、浏览器冒烟）已通过；安装包以本标签对应的 Desktop release 工作流结果为准。
- 浏览器冒烟测试使用模拟接口与生成的音频；不代替真实账户和原生环境验收。

保留的限制：

- 未用真实 QQ 音乐／网易云账号验证本版播放；未在 macOS 原生环境完整验收本版新功能；Windows、Intel Mac 原生行为不能由自动检查替代。
- Spotify／Apple Music 需要开发者密钥，尚未接入。
- 从文件导入的专辑仅本次运行可直接播放，重新打开后需再选一次文件。
- 月夜书桌的桌面像素验收脚本需要 Windows 环境，未在本次自动检查中运行。
- macOS 使用 ad-hoc 签名，尚未 Apple 公证；Windows 尚未配置发布者签名。

收藏与专注记录仍保存在本机。升级或换电脑前，可在“收藏与备份”导出备份。发行资产提供 SHA256SUMS.txt；请按设备架构选择 macOS arm64／x64 或 Windows x64 安装包。
