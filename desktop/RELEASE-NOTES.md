心流小屋 1.12.0：新增应用内「检查更新」（PR #17）。

- 启动后自动检查更新，也可以从「设置 › 关于」、托盘或应用菜单手动检查。
- 关于页面显示当前版本、更新说明、下载进度和安装状态，并提供「有新版本时自动下载」开关。
- Windows 安装版支持下载更新，下载完成后可选择「重启安装」，或在下次退出时安装。
- macOS 和 Windows 便携版会提示新版本，并打开对应架构的安装包下载。
- 发布资产新增自动更新元数据与增量下载文件。

升级说明
- v1.11.0 及更早版本没有应用内更新功能，需要手动下载安装本版；安装本版后才能检查后续版本。
- macOS 使用 ad-hoc 签名，尚未 Apple 公证，因此采用手动下载安装包的更新方式；Windows 尚未配置发布者签名。

验证范围
- PR #17 及合并提交的 GitHub Checks 已通过；各平台安装包须通过 Desktop release 工作流中的打包客户端检查后发布。
- Windows 真实跨版本下载、安装与重启流程尚未进行真机验收。

收藏与专注记录保存在本机。升级前可在「设置 › 数据与备份」导出备份。请根据设备选择 macOS arm64／x64 或 Windows x64 安装包；SHA256SUMS.txt 用于校验下载文件。
