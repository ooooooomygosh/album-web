心流小屋 1.10.0：歌单导入与无缝播放、唱机特写、桌面模式、学习工具，以及重新整理的小屋布局。

歌单与播放（PR #12）
- 导入「我的歌单」：支持网易云、QQ 音乐账号歌单、公开分享链接、macOS「音乐」App 歌单、Apple Music 公开链接与导出文件；歌单作为唱片摆上唱片架，可按「歌单」筛选。
- Apple Music 曲目通过版本匹配在 QQ 音乐／网易云播放；曲目之间无缝衔接，并缓存下一首。
- 唱机特写（快捷键 T）：近景唱机、唱片飞入动画，以及即将播放的曲目队列；加入待播时唱片会飞向待播按钮。

桌面模式与沉浸（PR #12）
- 桌面模式：小屋铺满桌面、待在所有窗口下面且可以直接操作；唱机、时钟、专注和待办成为可拖动的桌面小组件。
- 沉浸与全屏体验打磨，修复退出全屏与桌面模式状态问题。

学习与桌宠（PR #12）
- 新增「学习」标签：FSRS 记忆卡片、考试倒计时、每日目标与专注热力图。
- 桌宠可被拖拽抛出，有重力与闲逛；小猫起跳不再在半空停顿。

小屋布局（PR #13）
- 专辑信息条移到唱片架下方，左右按场景外框对齐，半透明背景、内容清晰；窄窗口使用带完整无障碍标签的图标按钮。
- 「筛选与唱片盒／布置小屋／音源设置」移到左侧「木屋唱机」标题下，筛选面板新增收起按钮。
- 专注面板改为右上角常驻计时徽章、按需展开；唱片架按实际面板位置避让，恢复场景边缘背景；900px 以下改为可收起的底部浮层。

已验证范围（2026-10-10）：

- PR #12、#13 的 GitHub Checks（单元测试、生产构建、浏览器冒烟）已通过；安装包以本标签对应的 Desktop release 工作流结果为准。
- 歌单导入使用离线夹具测试；浏览器冒烟测试使用模拟接口与生成的音频，不代替真实账户和原生环境验收。

保留的限制：

- 未用真实网易云／QQ 音乐账号、macOS「音乐」App 验证歌单导入与播放；Apple 曲目不是 MusicKit 播放。
- 桌面模式的真实 macOS／Windows 桌面层级行为未验收。
- Spotify 需要开发者密钥，尚未接入。
- 从文件导入的专辑仅本次运行可直接播放，重新打开后需再选一次文件。
- macOS 使用 ad-hoc 签名，尚未 Apple 公证；Windows 尚未配置发布者签名。

收藏与专注记录仍保存在本机。升级或换电脑前，可在“收藏与备份”导出备份。发行资产提供 SHA256SUMS.txt；请按设备架构选择 macOS arm64／x64 或 Windows x64 安装包。
